Peptide vendors spread across multiple affiliate platforms. Search each platform's merchant directory with the term set: **peptide, peptides, amino, aminos, lab, labs, research, bio** (chem/therapeutics returned nothing on GoAffPro — word-start matching). Biggest vendors (Peptide Sciences, Core, Limitless) often run IN-HOUSE programs (no network) — find via their own /affiliates page.

**KEY INSIGHT (RULE #0):** Mainstream affiliate networks (Impact, CJ, Awin, Rakuten, ShareASale) largely EXCLUDE research chemicals/peptides/SARMs via acceptable-use policies — searching them for peptide vendors mostly returns general supplement brands, NOT research peptides. So target those, skip the mainstream networks.
