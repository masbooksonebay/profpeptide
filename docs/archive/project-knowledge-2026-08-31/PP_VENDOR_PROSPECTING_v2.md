Traffic tiers are estimates (Similarweb/Ahrefs); treat as tiers (High/Med/Low/Insufficient-data), not precise counts. Verify a vendor is actually a peptide seller + check COA/testing + attribution model BEFORE applying — traffic alone isn't the filter. PP's "verified, not-aggregator" brand equity means high-traffic-but-low-transparency vendors can hurt more than help.

## 📋 HOW TO USE
- **Traffic tier** filled from Similarweb (trial active thru ~July 18 — USE THEN CANCEL) / Ahrefs checker.
- **Vet notes** = COA/testing transparency, attribution (code vs link), red flags.
- **Status** = prospect / applied / affiliate+page / affiliate-need-page / existing / rejected / skip.
- **Attribution note (PP-specific):** PP earns on CODE USE regardless of click, so short cookie windows matter LESS to us than to typical affiliates. Weight commission % + code-attribution + testing transparency over cookie duration.
