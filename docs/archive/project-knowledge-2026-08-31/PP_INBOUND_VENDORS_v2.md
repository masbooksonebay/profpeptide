## THE TWO GATES

Inbound vetting answers two independent questions. Conflating them is a mistake — a vendor can pass one cleanly and fail the other.

### 🔴 Gate A — Can PP get paid?

**The code must be bound to the affiliate account.** Hard gate, no exceptions.

A code that applies at checkout proves nothing about attribution. Vendors routinely create the requested code as a **standalone store coupon** and never link it to the affiliate ID — from their side they did exactly what was asked. Confirmed unbound on three vendors: Almighty, Spartan, Ignite. **Almighty ran 589 visits to zero attributed sales this way.**

This isn't a quality question. A vendor with flawless documentation and an unbound code is worthless commercially, because code attribution is PP's proven revenue mechanism — buyers read the code in a search result or an X post and go direct, never touching a link.

⚠️ **A vendor with no affiliate program hasn't failed this gate — it's unanswerable.** Setting one up is the first step, not a strike.

### ✅ Gate B — Is the vendor good enough to recommend?

**COA quality is the primary signal.** Everything PP claims rests on it.

Open a certificate and check:
- **Lab named**, and the search code resolves through the **lab's own verifier** — not a vendor-controlled QR
- **Client named in full**, not initials
- **Lot populated**, not blank
- **It's the actual peptide**, not bacteriostatic water
- Published **before purchase**, not on request

⚠️ **A COA proves what was in the tested lot. It does not prove what ships.** That's why pricing sanity remains an independent check — a counterfeiter can publish a genuine certificate for a genuine batch and ship something else. **Dramatically below market on GLP-1s is the tell no certificate catches.**

### Supporting signals — corroborate, don't decide

- **Operating entity identifiable.** Can the business behind the DBA be found and verified? A state registration lookup where a name is given. ⚠️ **A physical address is NOT required.** Online storefronts and dropship operations legitimately have nowhere to publish — Capstone Peptides LLC is exactly this shape. The concern is a vendor with *no traceable legal existence at all*, not a missing street address.
- **Contactability.** A named person or a real support channel. An email address and nothing else is thinner than a DBA without a warehouse.
- **Internal consistency.** Where a vendor makes a claim, it should hold up. Contradictory stats, a lab named in email but not on site, "since 2015" on a site built in January.
- **Site age** — under ~3 months, wait unless something else is compelling.
- **Review footprint** — Trustpilot, PeptideCritic, PeptiPrices, Reddit. Absence isn't disqualifying, but it removes the ability to verify anything.
- **Template artifacts** — demo search terms, Canva filenames with typos, AI-generated imagery (`Gemini_Generated_Image_*`, `ai-background-*`), placeholder coordinates. Cheap, reliable tells that a site isn't a real operation.

**No supporting signal is individually disqualifying. Three or more together means wait.**

### ⚠️ One gate the outbound standard doesn't cover

**Placement is not for sale.** Several inbound inquiries ask about "advertising partnership" or paid placement in guides. PP has no rate card and no listing fee. Say so plainly in the first reply — a vendor who only wants paid placement isn't a fit, and the ones who accept it are the ones worth having.

## THE CHECKLIST — run on each, same fields every time

**Gate A**
- Does an affiliate program exist? Which platform? Signup URL?

**Gate B**
- Open a certificate. Lab named? Search code resolving through the lab's own verifier? Client named in full? Lot populated? Actual peptide? Published pre-purchase?
- Pricing sanity — anything dramatically below market on GLP-1s?

**Supporting**
- Operating entity identifiable — registration lookup where a name is given *(no address required)*
- Contactability — named person or real support channel?
- Internal consistency — do the claims agree with each other?
- Site age · review footprint · template artifacts

**PP-specific practicalities**
- Prices publicly visible, or account-gated?
- Compounds named or coded? If coded, mechanistic evidence or naming convention only?
- Age gate or bot protection blocking the pull?

## STANDING NOTES

**Placement is not for sale.** No listing fee, no rate card. State it in the first reply to any inquiry mentioning advertising or paid placement.

**Ask for `PROFPEPTIDE` from the start.** Cheaper than a migration later — three vendors were migrated in August and each required reissuing live X posts, which are immutable.

**Commission ≠ customer discount.** Ask which number a vendor means. Valkyrie pays 20% and gives readers 10%.

**The backlink ask is optional and unconditional.** Tying a listing to a backlink would compromise the independence that makes the profile worth linking to. Currently two vendors link back — Legendary Peptides and Amino X. ⚠️ Amino X is at 74% out of stock and may be winding down.

**⚠️ Correction recorded Aug 13, 2026:** an earlier version of this doc treated a missing physical address as a vetting failure. That was wrong — online storefronts legitimately have nowhere to publish one, and **Capstone Peptides LLC is exactly that shape**. PP_VENDOR_PROSPECTING §1.3 reads more strictly than intended and should be revised to match: the check is whether the operating entity is **identifiable and verifiable**, not whether a street address appears.
