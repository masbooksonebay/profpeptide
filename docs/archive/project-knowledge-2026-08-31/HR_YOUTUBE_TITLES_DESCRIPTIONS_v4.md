## HOW TO USE

**Copy the title. Copy the description. Paste both. Nothing to assemble.**

**Title convention:**

```
HYROX [search phrase] | Week N Day N #HYROX #hyroxtraining #hybridtraining
```

The middle slot is a **search phrase, never the app's session name**. Range is 68–87 characters against YouTube's 100-character cap.

The grid truncates around 40 characters regardless of format, so trailing hashtags get visually clipped there — but they stay clickable on the watch page and still categorize the video. What matters is that the search phrase and week/day sit inside the visible portion.

**No "| Hybrid Rockstar" suffix.** The channel name renders under every video already — repeating it spent characters on nothing. The four Shorts published before July 30 carry it; don't retro-edit them.

**Never use YouTube's suggested hashtags.** It offers broad tags like `#motivation #sports #athlete`, which help YouTube bucket the video but do nothing for a niche channel. Specific beats broad.

**Four hashtags total per video** — three in the title (`#HYROX #hyroxtraining #hybridtraining`), one in the description (the session tag, which changes each upload). No duplication. The cap is 15; exceeding it makes YouTube ignore all of them.

**`#Shorts` is deliberately absent.** YouTube identifies a Short by aspect ratio and duration — a vertical video under three minutes is a Short whether or not it's tagged. The tag was needed in 2021 and isn't now, and its hashtag page is too large to aid discovery.

**Per upload:** Made for Kids → **No** · Visibility → **Scheduled** with a date · Category consistent across the channel.

**Filenames:** if CD exports each MP4 named as the full title string, YouTube pre-fills the title and you paste one field instead of two.

> **W1D1–W1D4 are published.** Their titles are listed for reference; don't retro-edit them. W1D1's description opens "Day 1 of the free 12-week…" — everything from W1D5 uses "Week N Day N of…" so it stays accurate as the program progresses.
