## 📊 §7 — EXTERNAL-AUDIT ROADMAP (NEW — sequenced implementation queue)

**Source:** Independent ChatGPT audit of profpeptide.com (browsing, no GSC/Ahrefs — so *prioritization* is data-blind; *strategy* is sound). Triaged against this doc + §6. Items the audit raised that **duplicate** existing work are folded into their §6 home, not re-listed.

**Tagging:** `[CC]` = CC-buildable researched/structured job · `[DECISION]` = needs Mark's call first · `[FAST]` = small/quick · `[PROJECT]` = larger build.

### 🚨 Tier 0 — FOUNDATION (do FIRST; fast; gates everything below)

**0a. Disclosure-contradiction FIX `[FAST][CC]` — legal/trust, same-day, non-negotiable.**
The Disclaimer page states the site is *"not affiliated with, sponsored by, or compensated by any peptide vendor"* — directly contradicting the About + coupon pages, which correctly disclose affiliate compensation. On a trust-moat site this is an **FTC-exposure + reputational** liability, not an SEO nicety. Reconcile the Disclaimer to match the affiliate disclosure (e.g. *"independently operated; may receive affiliate commissions… relationships do not determine inclusion, ranking, or editorial conclusions"*). Add a short "How affiliate relationships work" block to coupon/vendor pages. **Do before any new content ships.**

**0b. Author identity + editorial-methodology page `[DECISION → then CC]` — E-E-A-T foundation.**
Biggest *structural* SEO gap. Pages carry "last reviewed" dates but **no named author/reviewer**; no methodology/about-how-we-verify page. E-E-A-T is **site-level** — establishing "who runs this + how claims are verified" FIRST means every later asset (COA index, calculators, guides, trackers) inherits the credibility. Retrofitting bylines later = rework.
- **DECISION PENDING (Mark):** authorship presentation — **named founder** (Mark; "30+ yr lifter / attorney" = strong personal E-E-A-T, ties site to him) vs **"Prof. Peptide editorial team"** brand voice (scalable, thinner E-E-A-T) vs **hybrid** (named founder + editorial process). Determines how the methodology page is drafted.
- **Cheap half (do now):** author identity/byline + `/methodology` (or `/editorial-standards`) page — who, sourcing standards, how pages are researched/verified, RUO stance, update cadence.
- **Expensive half (later, deliberate investment):** paid PharmD/MD/PhD review of the ~20 highest-risk pages (Reta, Tirz, Sema, BPC-157, TB-500, CJC/Ipa, MT-II, PT-141, "where to buy," calculators). NOT required now — banked as a strategic YMYL-moat investment.

### 🏛️ Tier 1 — THE KEYSTONE ASSET (start once Tier 0 lands)

**1. Vendor COA / Testing-Transparency Index `[PROJECT][CC]` — the missing backlink strategy.**
Highest *ceiling* asset + the audit's "do this first." Turns the trust moat (currently editorial prose) into a **citable, linkable asset** — the structural version of "compete on trust, not inflated discount numbers." **Built largely from data already collected** on vendor pages (per-vendor verified differentiators: Amino Club ISO 17025, Glacier batch-traceable COAs + cold-chain, Peptide Partners 4 independent batch tests, Ascension HPLC-UV-MS via MZ Biolabs, Vital Core per-product COAs). Feeds the vendor-promotion playbook.
- **Page:** `/vendor-testing-index/` (or `/peptide-vendor-coa-index/`). Columns: vendor · compound coverage · batch-specific COA availability · HPLC/MS · sterility/endotoxin/heavy-metals · lab name · public COA URL · **last manually verified date** · price-per-mg (common compounds) · lab-portal/QR verifiable? · notes.
- **Link-earning hooks:** downloadable CSV; "submit a correction / submit a COA" form; (optional, later) quarterly blind-test of 3–5 popular compounds, published. Outreach target for testing-obsessed communities + journalists — citable *without* linking to a coupon page.
- **RULE #0:** every cell verified; each vendor's differentiator is its OWN (never borrowed).

### 🎯 Tier 2 — HIGH-INTENT, APP-ADJACENT (queue as CC frees up; build in order — guides link to calculators)

**2. Compound-specific reconstitution calculator landing pages `[PROJECT][CC]`.**
Strongest *commercial-intent* fit + directly funnels the **app** (whose reconstitution feature is being updated now). Wins long-tails we *can* own (won't beat Mayo/GoodRx on "tirzepatide dosage"; *can* win "tirzepatide reconstitution calculator," "X mg vial units," "semaglutide units calculator").
- `/calculator/tirzepatide-reconstitution`, `/semaglutide-`, `/retatrutide-`, `/bpc-157-` (+ extend). Preset vial sizes, BAC-water volumes, formula transparency, RUO/verify-independently block, **app CTA**. Frame as concentration/draw-volume math — NOT medical dosing advice.

**3. Guides cluster expansion `[PROJECT][CC]` — build AFTER #2 (guides cross-link into calculators).**
Guides hub currently shows only ~2 visible guides. Build the "Peptide Research Starter Path" (8–12): reconstitution step-by-step, BAC vs sterile water, lyophilized storage, U-100 syringe units, vial concentration, **COA verification / how to read HPLC-MS**, sterility/endotoxin basics, vendor-comparison method, avoiding double-dosing in blends, research-log best practices. Each peptide page's calculator CTA links into the relevant guide. (COA-verification guide ↔ the Tier-1 index.)

### 📚 Tier 3 — DEPTH + PR (steady background; lower marginal value — bank behind Tiers 0–2)

**4. News → evergreen trackers `[PROJECT][CC]` — pairs with the COA index as PR.**
News decays; data-rich trackers earn links. Convert the (strong, current) /news beat into evergreen assets: `/trackers/fda-peptide-compounding-status/`, `/glp1-pipeline/`, `/peptide-regulatory-timeline/`, `/retatrutide-approval-timeline/`. Each: dates · primary-source links · what changed / what didn't · affected peptides-vendors-users · "last verified." Pitch to journalists/newsletters/communities.

**5. GLP-1 side-effect cluster `[CC]` — connects to the news beat (already covered muscle-loss/activity-decline).**
Hub `/guides/glp-1-side-effects/` + children (nausea, fatigue, constipation, muscle loss, dysesthesia, menstrual changes, alcohol, mood/reward, exercise decline, stopping/regain). Separate FDA-approved-medication data from research-grade/unapproved-peptide uncertainty. (Audit confidence: medium — data-blind on volume; verify intent before over-building.)

**6. Retatrutide clinical-trial/approval hub `[CC]` + research-only relabel.**
Won't beat Lilly/GoodRx/NEJM on the head term; *can* win "retatrutide trial tracker / approval timeline / results table." `/guides/retatrutide-clinical-trials` (TRIUMPH/TRANSCEND tracker). On `/peptides/retatrutide`: move vendor cards lower + label **"research-only; not prescription availability"** (compliance-aligned given official trial-only warnings). (Overlaps existing Reta depth — lower marginal value.)

**7. BPC-157 evidence map `[CC]`.**
Gap isn't "what is BPC-157" — it's structured **evidence quality**: `/guides/bpc-157-evidence-map/` matrix (claim → model studied → human evidence? → grade → risk flags → PubMed). Internally link from BPC-157/TB-500/Wolverine/GLOW/KLOW/recovery/vendor pages. Citation-heavy → linkable by skeptical communities.

**8. Peptide stack overlap / safety checker `[PROJECT][CC]` — lowest urgency (tool build).**
`/tools/peptide-stack-checker/` (or static matrix first): select peptides → overlapping mechanisms, shared side effects, WADA/regulatory status, injection burden, half-life conflicts, **duplicated components** ("KLOW already contains BPC-157/TB-500/GHK-Cu/KPV"). Matches existing KLOW editorial stance. More defensible than a "best stacks" affiliate article.
