## 1. THE VETTING STANDARD

Before a newly-discovered vendor gets a page:

**0. 🔴 CONFIRM THE CODE IS BOUND TO THE AFFILIATE ACCOUNT.** *(Outranks the other five — added Aug 8 2026.)*

A code that applies at checkout proves **nothing** about attribution. Vendors routinely create the code Mark asks for as a **standalone store coupon** and never link it to his affiliate ID — from their side they did exactly what was requested.

Ask the vendor directly: *"Is this code linked to my affiliate account, or is it a standalone store coupon?"* Then verify a coupon shows as **attached** in the portal.

**Confirmed unbound on three vendors: Almighty, Spartan, Ignite.** Almighty ran **589 visits to zero attributed sales** this way. Full signature and per-vendor status in **PP_COMMISSIONS §2**.

⚠️ **A vendor who won't bind the code isn't viable.** Code attribution is PP's proven revenue mechanism — buyers read the code in a search result or an X post and go direct, never touching a link. An unbound code means PP promotes a discount for free.

1. **Site age** — asset upload dates, copyright year, domain registration. Under ~3 months = wait unless something else is compelling.
2. **Independent review footprint** — Trustpilot, PeptideCritic, PeptiPrices, Reddit. Absence isn't disqualifying alone, but it removes the ability to verify anything.
3. **Verifiable US-registered entity + physical address.** A state registration lookup takes two minutes. Naming an LLC beats naming nothing; naming nothing is the strongest single signal.
4. **COA library contents, not its existence.** A `/coas` link proves nothing until a certificate is opened.
5. **Pricing sanity** — dramatically below market on GLP-1s is a known counterfeit signal.

**None of 1–5 is individually disqualifying. Three or more together means wait.** Check 0 is different — it's a hard gate.

## 1b-3. 🆕 COMMISSION ≠ CUSTOMER DISCOUNT — a recurring trap

GoAffPro portals show **two different percentages** and they are frequently not equal:

| Vendor | Commission to PP | Discount to buyer |
|---|---|---|
| AMP | 15% | 15% |
| Improved | **20%** | **15%** |
| Valkyrie | **20%** | **10%** |

**Rule: the page states the CUSTOMER discount. The commission never appears anywhere on PP.** Every onboarding prompt must state both explicitly and say which is which.

⚠️ **Valkyrie is the asymmetric case** — pays the most, gives the reader the least. Worth asking them to raise the customer-side discount, since code attribution is where PP's volume actually is.

## 1b-4. 🆕 COUPON CASE — TEST IT, DON'T ASSUME

GoAffPro displays the coupon **lowercase** (`profpeptide`) while the referral parameter is **uppercase**. PP publishes uppercase by convention.

**Verified empirically, twice, in a live cart:**

## 1b-7. 🆕 A NEW DISQUALIFIER PATTERN — the vendor-controlled QR

**Add to the four patterns in §1b.**

**A verification QR that resolves to the vendor's own site rather than the issuing lab's verifier.**

The QR exists so a buyer can confirm a certificate independently of the vendor. One pointing back at the vendor inverts that entirely — it's a link the seller controls, on a document the seller is asking you to trust.

### 🔴 A failed fetch is NOT a failed check

If a site blocks automated access, that is a statement about **our access**, not about the vendor.

**Try the direct-asset path first** — `/wp-content/uploads/…` PDFs and images return 200 even where the HTML 403s a bot. This works on most WordPress vendors and is how five vendors' certificates were finally read.

If that fails too, report **UNREACHABLE-BY-FETCH** and **ask Mark for a paste.** Never record "no COA," "COAs on request," or "fails check 4" from a fetch failure.

> Five roster vendors had their testing understated because a fetch obstacle was converted into a claim about them. Every vendor on the roster publishes COAs from real labs. **Assume they do; ask when you can't see it.**

### On the origin question

A rule reading "brand name sounds foreign" is unreliable and not something to put in writing on a site PP operates. Most research peptides are synthesized in China regardless of seller. **The meaningful distinction is whether a US entity is accountable** — no named entity, no address, template copy, no accumulating COA record. That's what checks 3 and 4 already test.
